# Kiến trúc Bảng Sửa đổi (V3) — Đề xuất sau Thảo luận

---

## 1. Vấn đề cốt lõi: Quá nhiều bảng, tên gây nhầm lẫn

Hiện tại schema V2 có 6 bảng riêng biệt cho thiết kế + khuôn:

```
design_masters ──┐
design_projects ─┤  ← 3 bảng thiết kế, chồng chéo
mold_designs ────┘
mold_masters ────┐
mold_revisions ──┤  ← 3 bảng khuôn
physical_molds ──┘
```

**Vấn đề:** `design_masters` và `mold_masters` gần như cùng vai trò (danh tính gốc). `mold_designs` thực chất là "phiên bản thiết kế" nhưng tên gọi lại giống "thiết kế khuôn".

## 2. Đề xuất: Gộp thành 4 bảng rõ ràng

```
products ─── "Sản phẩm khay JAE-351"
  │
  └── mold_masters ─── "Danh tính gốc: JAE-351AB"
        │                (gộp design_masters + mold_masters + design_projects)
        │
        ├── design_revisions ─── "Phiên bản thiết kế: R0, R1, R2..."
        │     (đổi tên từ mold_designs, gộp thêm design_projects)
        │     (25+ thông số kỹ thuật + trạng thái duyệt + designer + file)
        │
        ├── mold_revisions ─── "Phiên bản gia công khuôn"
        │     │                 (liên kết tới design_revision được duyệt)
        │     │
        │     └── physical_molds ─── "Khuôn vật lý trên kệ"
        │
        └── cutter_masters → cutters
```

### Luồng nghiệp vụ với kiến trúc mới:

```
① Kinh doanh nhận đơn JAE-351
   → Tạo products: {product_code: "JAE-351"}
   → Tạo mold_masters: {master_code: "JAE-351AB"}

② Thiết kế lần 1 (chưa duyệt)
   → Tạo design_revisions: {
       revision_code: "JAE-351AB",     ← phiên bản gốc (không có -R)
       status: "DRAFT",
       designer_id: → Endo,
       design_length: 469, design_width: 299,
       cutline_length: 350, cutline_width: 270,
       corner_r: 10, ...
     }

③ Khách yêu cầu sửa → Thiết kế lần 2
   → Tạo design_revisions: {
       revision_code: "JAE-351AB-R1",
       status: "DRAFT",
       ...thông số mới...
     }

④ Khách yêu cầu sửa tiếp → Thiết kế lần 3
   → Tạo design_revisions: {
       revision_code: "JAE-351AB-R2",
       status: "APPROVED",           ← ĐÃ DUYỆT
       approved_date: "2026-03-15",
       ...thông số cuối...
     }

⑤ Chế tạo khuôn (dựa trên R2 đã duyệt)
   → Tạo mold_revisions: {
       revision_code: "JAE-351AB-R2",
       design_revision_id: → bản R2 ở trên,
       reason: "初回製作"
     }
   → Tạo physical_molds: {
       system_code: "JAE-351AB-R2",
       display_name: "JAE-351 AB R2",
       mold_revision_id: → trên,
       rack: #12-3, keeper: YSD
     }

⑥ 1 năm sau: Sửa khuôn (thêm pocket)
   → Tạo design_revisions MỚI: {
       revision_code: "JAE-351AB-R3",
       status: "APPROVED",
       pocket_count: 5, corner_r: 15
     }
   → Tạo mold_revisions MỚI: {
       revision_code: "JAE-351AB-R3",
       design_revision_id: → R3,
       reason: "追加ポケット"
     }
   → physical_molds: CẬP NHẬT mold_revision_id → R3

⑦ Khuôn hư, làm bản sao
   → Tạo physical_molds MỚI: {
       system_code: "JAE-351AB-R3-N1",
       copy_number: 1,
       mold_revision_id: → R3 (cùng revision)
     }
```

**Truy vết:** Từ khuôn vật lý `JAE-351AB-R3-N1` → tra `mold_revisions` R3 → tra `design_revisions` R3 (bản duyệt) → tra ngược thấy R2, R1, R0 (lịch sử thiết kế) → tra `mold_masters` JAE-351AB → tra `products` JAE-351. ✅

## 3. Chi tiết cột cho từng bảng mới

### 3a. `mold_masters` (gộp design_masters + mold_masters + design_projects)

| Cột | Kiểu | Ý nghĩa |
|:---|:---|:---|
| `master_id` | UUID PK | |
| `master_code` | TEXT UNIQUE | Mã gốc: JAE-351AB |
| `master_name` | TEXT | Tên hiển thị |
| `product_id` | FK → products | Sản phẩm liên quan |
| `company_id` | FK → companies | Khách hàng sở hữu |
| `designer_id` | FK → employees | Người thiết kế chính |
| `cad_folder_path` | TEXT | Đường dẫn thư mục CAD |
| `mold_class` | TEXT | STD/CUSTOM |
| `mold_source` | TEXT | INTERNAL/EXTERNAL |
| `status` | TEXT | ACTIVE/ARCHIVED |
| `legacy_id` | TEXT | Ánh xạ ID cũ |

### 3c. `mold_revisions` (giữ nguyên — phiên bản gia công)

| Cột | Kiểu | Ý nghĩa |
|:---|:---|:---|
| `revision_id` | UUID PK | |

| `design_revision_id` | FK → design_revisions | **Bản thiết kế nào được dùng để gia công** |

## 4. Thuật ngữ thống nhất

| Khái niệm | Tên cột | Giải thích |
|:---|:---|:---|
| Số sản phẩm/mặt trên 1 khuôn | `cavity_count` | 面取数 / 取り数. Dùng cho cả khuôn và dao cắt |
| Số pocket trên 1 khay | `pocket_count` | Số hốc trên 1 sản phẩm khay |
| Quy cách khung khuôn (YSD) | `cav_type_id` → bảng `cav_types` | Kích thước ngoài chuẩn (574×374, 620×820...) — giữ tên "CAV" vì là thuật ngữ nội bộ YSD |
| Thông số undercut | `undercut_spec` | TEXT dạng "8.6x5" |
| Tên sản phẩm | `product_name` | Bỏ hậu tố `_ja`. Tên chính thức từ khách |
| Tên nội bộ YSD | `product_name_internal` | Tên do kinh doanh YSD đặt (nếu khác) |

## 5. Quy tắc đặt tên Đơn hàng (Order)

Dựa trên thực tế:
- `JAE-351  025-60249(20250610)JAE三橋様 初回`
- `SMK 167CLE-007-01F G-020-1(20210224)`

**Đề xuất cấu trúc `order_code`:**

```
{Mã_khuôn_YSD}_{Mã_KH}_{Ngày_xuất}
```

Ví dụ: `JAE-351AB_025-60249_20250610`

Và lưu thêm các trường riêng:
| Cột | Ví dụ | Ghi chú |
|:---|:---|:---|
| `order_code` | `JAE-351AB_025-60249_20250610` | Mã tự sinh theo quy tắc |
| `customer_order_no` | `025-60249` | Mã đơn hàng phía khách |
| `customer_product_code` | `167CLE-007-01F` | Mã sản phẩm phía khách |
| `mold_code_ref` | `JAE-351AB` hoặc `G-020-1` | Khuôn sử dụng |
| `ship_date` | `2025-06-10` | Ngày xuất hàng |
| `recipient_name` | `三橋様` | Người nhận |
| `order_type` | `INITIAL` / `REPEAT` | 初回 / リピート |

## 6. Tổng kết thay đổi so với Schema V2

| Thay đổi | Chi tiết |
|:---|:---|
| **XÓA** `design_masters` | Gộp vào `mold_masters` |
| **XÓA** `design_projects` | Gộp vào `design_revisions` |
| **ĐỔI TÊN** `mold_designs` → `design_revisions` | Thêm cột: status, designer_id, approved_date, cad/pdf paths |
| **CẬP NHẬT** `mold_masters` | Thêm cột từ design_masters: designer_id, cad_folder_path |
| **ĐỔI TÊN CỘT** trong `design_revisions` | cutline_x→cutline_length, cutline_y→cutline_width, piece_count→cavity_count, under_angle→undercut_spec |
| **ĐỔI TÊN CỘT** trong `cutters` | blade_count→cavity_count |
| **ĐỔI TÊN CỘT** trong `products` | product_name_ja→product_name, thêm product_name_internal |
| **THÊM CỘT** vào `companies` | address, tel, fax, notes |
| **THÊM CỘT** vào `orders` | customer_order_no, customer_product_code, mold_code_ref, recipient_name |
| **THÊM CỘT** tất cả bảng chính | legacy_id TEXT, legacy_specs JSONB |
